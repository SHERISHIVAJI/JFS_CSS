Demo of :indeterminate

Indeterminated Checkbox

The checkbox below is in an indeterminate state (by JavaScript). If you click on it, it is no longer indeterminated.

Note that an indeterminate checkbox has a "-" icon, rather than a checkmark or an empty box.

Indeterminated Radio buttons

Radio buttons are in an indeterminate state when all radio buttons with the same name value in the form are unchecked
